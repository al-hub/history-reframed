# History Reframed

> Historical figures, reframed for intuitive understanding.
>
> 역사적 주요 인물의 삶을 오늘날 감각으로 직관적으로 이해할 수 있도록 프로필과 인생 타임라인으로 재구성합니다.

## 목적

역사적 사실을 기반으로 하되, 당시의 관직·경력·삶의 굴곡을 오늘날의 직업·취업·조직생활 표현으로 비유해 인물을 쉽고 재미있게 이해하는 프로젝트입니다.

- **역사적 사실**과 **비유·해석**을 구분합니다.
- MBTI·취미·특기 등의 항목은 기록을 바탕으로 한 **캐릭터 해석**이며 실제 검사 결과가 아닙니다.
- 야사·생존설 등은 정사와 구분하여 표시합니다.
- 직급·조직 등의 표현은 당시 제도와 1:1 대응하지 않으며 오늘날 감각으로 이해하기 위한 비유입니다.

## 주의

이 저장소는 역사 인물을 친숙하게 이해하기 위한 **reframing 프로젝트**입니다. 학술적 전기 자체를 대체하지 않습니다. 직급, MBTI, '취업', '해고' 같은 표현은 역사적 사건을 **오늘날 감각으로 이해하기 위한 비유**입니다.
