# 🇰🇷 정약용

## 기본소개

**이름 : 정약용(다산)**  
**업적 : 조선의 개혁안을 집대성함**  
**출생 : 1762년 경기도 양근**  
**직업 : 관료, 학자, 개혁사상가**  
**MBTI : INTJ 느낌**  
**취미 : 독서, 글쓰기, 제도 뜯어보기, 기술 아이디어 구상**  
**특기 : 문제 분석, 제도 설계, 행정·법·경제를 한 번에 연결하기**  
**극혐 : 탁상행정, 부패, 백성 괴롭히는 관리, 비효율**  
**성격 : 분석적 + 실용적 + 오래 버티는 연구형 인간**  
**좌우명 : 백성에게 실제로 도움이 되는 제도를 만들자**

> 직업·조직·MBTI 등의 표현은 정약용의 삶을 **오늘날 감각으로 이해하기 위한 비유**입니다.

## 요약

**공부 잘하는 관료 지망생 → 27세 문과 급제 → 정조의 핵심 실무형 인재 → 행정·기술·감찰 경험 → 정조 사후 정치적 급변 → 39세 체포·유배 → 18년 장기 유배 → 유배지에서 수백 권 분량 연구·저술 → 『목민심서』·『경세유표』·『흠흠신서』 → 조선 개혁안의 종합설계자**

> **업적 : 조선의 개혁안을 집대성함.**

## 인생

### 양근 출생 (0세 · 1762년)
→ 경기도 양근에서 출생  
→ 남인계 학문 분위기 속에서 성장

### 시험과 공부 (21세 · 1783년)
→ 1783년 진사시 합격  
→ 성균관에서 학문을 깊게 익힘

### 공무원 합격 (27세 · 1789년)
→ 1789년 문과 급제  
→ 정조의 신임을 받으며 여러 관직 수행

### 실무형 엘리트 (27~38세 · 1789~1800년)
→ 암행어사·지방행정·형조 등 다양한 행정 경험  
→ 수원 화성 건설 과정에서 기술·공학적 아이디어에도 참여  
→ 행정만 하는 문신이라기보다 **정책 + 현장 + 기술을 같이 보는 문제해결형 관료**에 가까움

### 정치환경 급변 (38~39세 · 1800~1801년)
→ 1800년 정조 사망  
→ 1801년 신유박해 과정에서 체포  
→ 천주교 관련 문제와 정치적 탄압이 겹치며 유배

### 18년 장기 유배 (39~56세 · 1801~1818년)
→ 전남 강진에서 장기간 유배생활  
→ 현장에서 백성의 삶을 보고 제도 문제를 정리  
→ 경학·정치·경제·행정·법률을 아우르는 방대한 저술

### 유배 해제 (56세 · 1818년)
→ 1818년 유배에서 풀려남  
→ 『목민심서』 등 핵심 저술 정리  
→ 공직 복귀보다 연구와 저술에 집중

### 연구자 인생 마무리 (73세 · 1836년)
→ 1836년 사망  
→ 후대에는 조선 후기 실학을 집대성한 인물로 평가

## 캐릭터 요약

**INTJ 느낌**  
→ 문제를 구조화하고 제도 전체를 다시 설계하는 타입

**특징**  
→ 정치적으로 밀려난 18년을 커리어 공백으로 끝내지 않고 거대한 연구기간으로 바꿈  
→ 오늘 식으로 보면 **강제 장기휴직 중 국가 운영 매뉴얼을 거의 새로 작성한 사람**에 가깝다.

## 사실 / 비유 / 설

- **역사적 사실:** 1762년 출생, 1783년 진사시, 1789년 문과 급제, 정조대 관료활동, 1801년 유배, 1818년 해배, 『경세유표』·『목민심서』·『흠흠신서』 등 방대한 저술, 1836년 사망.
- **비유:** 공무원 합격, 실무형 엘리트, 강제 장기휴직, 국가 운영 매뉴얼, INTJ.
- **해석이 필요한 부분:** 기술자·개혁가 이미지의 강도는 여러 활동을 압축한 표현이다.
- **후대의 설·야사:** 거중기를 정약용이 혼자 발명했다는 식의 표현은 피한다. 화성 축성 과정의 기술 적용과 설계 기여로 보는 것이 안전하다.
