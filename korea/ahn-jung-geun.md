# 🇰🇷 안중근

## 기본소개

**이름 : 안중근**  
**업적 : 하얼빈에서 이토 히로부미를 처단하고 독립 의지를 세계에 알림**  
**출생 : 1879년 황해도 해주**  
**직업 : 의병, 독립운동가**  
**MBTI : ENTJ 느낌**  
**취미 : 사냥, 사격, 말타기, 서예**  
**특기 : 사격, 결단, 조직, 행동으로 옮기기**  
**극혐 : 침략, 주권 침탈, 말뿐인 애국, 비겁한 타협**  
**성격 : 직선적 + 결단력 강함 + 신념이 행동으로 바로 이어지는 타입**  
**좌우명 : 위국헌신 군인본분(爲國獻身 軍人本分)**

> 직업·조직·MBTI 등의 표현은 안중근의 삶을 **오늘날 감각으로 이해하기 위한 비유**입니다.

---

## 요약

**사냥·사격 좋아하던 청년 → 천주교 세례 → 교육·계몽운동 → 나라가 기울자 의병전으로 전환 → 연해주에서 무장투쟁 → 동지들과 단지 → 30세 하얼빈역에서 이토 히로부미 사살 → 현장 체포 → 재판에서 개인 암살이 아니라 군인으로서의 전투행위라고 주장 → 옥중에서 자서전·동양평화론 집필 → 30세 순국**

> **업적 : 짧은 생애를 독립운동과 동양평화 구상으로 압축함.**

## 인생

### 해주 출생 (0세 · 1879년)
→ 황해도 해주에서 출생  
→ 어린 시절 서당 공부와 함께 사냥·사격을 즐김

### 신앙과 새로운 세계 (10대 후반)
→ 천주교 입교  
→ 세례명 토마스  
→ 서양 지식과 교육의 필요성에 관심

### 교육으로 나라를 살려보려 함 (20대 중반)
→ 학교 운영과 계몽활동  
→ 처음에는 교육과 실력양성을 통한 대응에 힘씀

### 교육만으로는 부족하다고 판단 (20대 후반)
→ 연해주로 이동  
→ 대한의군 활동과 의병전 참여  
→ 무장투쟁으로 방향 전환

### 단지동맹 (30세 · 1909년)
→ 동지들과 손가락을 끊어 피로 맹세  
→ 이토 히로부미와 이완용 제거를 결의

### 하얼빈 (30세 · 1909년 10월 26일)
→ 하얼빈역에서 이토 히로부미를 사살  
→ 현장에서 체포  
→ 개인적 원한에 의한 살인이 아니라 **대한의군 참모중장 자격의 군사행동**이라고 주장

### 감옥에서도 멈추지 않음 (30세 · 1909~1910년)
→ 『안응칠역사』 집필  
→ 동아시아 국가들이 공존하는 방안을 담은 『동양평화론』 집필 시작  
→ 완성하지 못함

### 순국 (30세 · 1910년 3월 26일)
→ 뤼순감옥에서 사형 집행  
→ 매우 짧은 생애였지만 이후 독립운동의 상징적 인물로 남음

## 캐릭터 요약

**ENTJ 느낌**  
→ 목표 설정 → 조직 → 실행까지 속도가 빠른 타입

**다만 단순한 행동파만은 아님**  
→ 교육운동, 종교, 자서전, 『동양평화론』까지 이어진 점을 보면 행동과 사상을 함께 가진 인물

---

## 사실 / 비유 / 설

- **역사적 사실:** 1879년 출생, 천주교 세례, 교육활동, 연해주 의병활동, 1909년 단지동맹, 하얼빈 의거, 체포와 재판, 옥중 저술, 1910년 순국.
- **비유:** ENTJ, 행동으로 바로 옮기는 타입, 교육만으로는 부족하다고 판단한 커리어 전환.
- **해석이 필요한 부분:** 성격·극혐 항목은 자서전과 행적에서 드러나는 태도를 압축한 것이다.
- **주의:** 하얼빈 의거는 당시 식민지 침탈과 무장독립운동의 역사적 맥락 속에서 다룬다.
