# 🇰🇷 세종대왕

## 기본소개

**이름 : 세종(이도)**  
**업적 : 백성이 쓰는 문자를 만들고 나라 시스템을 업그레이드함**  
**출생 : 1397년 한성**  
**직업 : 조선 제4대 왕**  
**MBTI : INTJ 느낌**  
**취미 : 독서, 토론, 연구, 음악·과학 챙기기**  
**특기 : 인재 등용, 제도 설계, 문제를 끝까지 파고들기**  
**극혐 : 백성이 몰라서 손해 보는 것, 대충 만든 제도, 무능한 보고**  
**성격 : 집요한 학구파 + 실용주의 + 인재를 쓰는 리더**  
**좌우명 : 백성이 쉽게 배우고 쓰게 하자**

> 직업·조직·MBTI 등의 표현은 세종의 삶을 **오늘날 감각으로 이해하기 위한 비유**입니다. 실제 역사적 인물의 성격검사 결과가 아닙니다.

## 요약

**왕자 → 왕위와 거리가 있던 셋째 아들 → 21세 즉위 → 집현전·인재풀 운영 → 농업·과학·음악·법·국방 전방위 개선 → 46세 훈민정음 창제 → 49세 반포 → 조선의 운영체계를 크게 업그레이드**

> **업적 : 백성이 쓰는 문자를 만들고 나라 시스템을 업그레이드함.**

## 인생

### 왕실의 셋째 아들 (0세 · 1397년)
→ 태종과 원경왕후의 셋째 아들로 출생  
→ 처음부터 왕위 1순위는 아니었음

### 예상 밖 후계자 (21세 · 1418년)
→ 형 양녕대군이 세자에서 폐위  
→ 충녕대군이 세자로 책봉  
→ 1418년 21세에 즉위

### 조직부터 만든다 (23세 · 1420년)
→ 1420년 집현전 설치  
→ 학자를 모아 정책·학문·편찬을 함께 수행  
→ 혼자 다 하는 왕보다 **좋은 인재를 모아 문제를 푸는 PM**에 가까운 운영

### 나라 전체를 손본다 (32–46세 · 1429–1443년)
→ 농업 지식 정리와 『농사직설』 편찬  
→ 천문·역법·측우·시간 측정 등 과학기술 발전 지원  
→ 박연 등과 음악·악기·악제 정비  
→ 북방 4군 6진 개척으로 국방 강화

### 문자 프로젝트 (46세 · 1443년)
→ 1443년 훈민정음 28자 창제  
→ 한자를 배우기 어려운 백성이 자신의 말을 글로 적을 수 있는 체계를 만듦

### 정식 배포 (49세 · 1446년)
→ 1446년 『훈민정음』 해례와 함께 반포  
→ 창제 원리와 사용법까지 설명  
→ 단순히 문자만 만든 것이 아니라 **사용설명서까지 붙인 플랫폼 출시**에 비유 가능

### 끝까지 일하다 (52세 · 1450년)
→ 시력·당뇨로 추정되는 증상 등 건강 악화 속에서도 국정 지속  
→ 1450년 52세로 사망

## 캐릭터 요약

**INTJ 느낌**  
→ 큰 그림 · 시스템 설계 · 깊은 연구 · 좋은 인재 활용

**리더십**  
→ 전문가를 모으고 직접 질문하며 끝까지 검증  
→ 결과물이 백성에게 실제로 도움이 되는지 중시

## 사실 / 비유 / 설

- **역사적 사실:** 1397년 출생, 1418년 즉위, 집현전, 과학·농업·음악·국방 정책, 1443년 훈민정음 창제, 1446년 반포, 1450년 사망.
- **비유:** PM, 플랫폼 출시, 나라 시스템 업그레이드, INTJ.
- **해석이 필요한 부분:** 취미·성격·극혐은 세종의 독서량, 정책 운영, 실록 기록을 오늘날 익숙한 표현으로 압축한 것.
- **후대의 설·야사:** 건강·식습관에 관한 세부 묘사는 기록 해석에 따라 차이가 있어 과도하게 단정하지 않는다.
