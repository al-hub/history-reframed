# 🇺🇸 에이브러햄 링컨

## 기본소개

**이름 : 에이브러햄 링컨**  
**업적 : 내전 속 연방을 지키고 노예해방의 전환점을 만듦**  
**출생 : 1809년 미국 켄터키**  
**직업 : 변호사, 정치인, 미국 제16대 대통령**  
**MBTI : INFJ 느낌**  
**취미 : 독서, 이야기하기, 유머, 토론, 레슬링**  
**특기 : 연설, 설득, 갈등 조정, 어려운 문제를 쉬운 말로 설명하기**  
**극혐 : 연방 분열, 노예제의 확대, 허세, 논리 없는 주장**  
**성격 : 조용하지만 집요함 + 유머 + 강한 도덕적 고민 + 현실정치 감각**  
**좌우명 : 국민의, 국민에 의한, 국민을 위한 정부**

> 직업·조직·MBTI 등의 표현은 링컨의 삶을 **오늘날 감각으로 이해하기 위한 비유**입니다. 노예제와 인종에 관한 그의 입장은 시대와 정치 상황 속에서 변화했기 때문에 한 문장으로 단순화하지 않습니다.

## 요약

**개척지 가난한 집 출생 → 정규교육 거의 없이 독학 → 노동·가게일·민병대 → 25세 주의원 → 독학으로 변호사 → 정치 실패도 여러 번 → 49세 상원의원 선거 패배하지만 토론으로 전국구 스타 → 51세 대통령 → 취임하자마자 남북전쟁 → 연방 유지에 올인 → 노예해방선언 → 게티즈버그 연설 → 재선 → 전쟁 승리 직전 → 56세 암살**

> **업적 : 나라가 둘로 갈라질 때 연방을 지키고 전쟁의 의미를 자유와 해방 쪽으로 바꿈.**

## 인생

### 개척지 오두막 출생 (0세 · 1809년)
→ 켄터키에서 출생  
→ 어린 시절 가족과 함께 인디애나 등으로 이동  
→ 농사·육체노동을 하며 성장

### 거의 독학 (10–21세 · 1819–1830년)
→ 정규 학교교육은 매우 제한적  
→ 책을 빌려 읽으며 스스로 공부  
→ 농장일, 뗏목 운송, 가게 점원 등 여러 일을 경험

### 첫 정치 도전 (23세 · 1832년)
→ 일리노이 주의회 선거 출마  
→ 낙선  
→ 같은 해 블랙호크 전쟁에서 민병대 대위로 복무

### 정치 입문 성공 (25세 · 1834년)
→ 1834년 일리노이 주의회 당선  
→ 법률 공부를 계속함

### 독학 변호사 (27세 · 1836년)
→ 변호사 자격 취득  
→ 스프링필드에서 변호사로 활동  
→ 순회재판을 다니며 논리·말하기·사람 읽는 능력을 키움

### 연방 하원의원 (37세 · 1846년)
→ 1846년 연방 하원의원 당선  
→ 한 임기 후 다시 변호사 생활 중심

### 선거는 졌는데 전국구가 됨 (49세 · 1858년)
→ 스티븐 더글러스와 상원의원 선거 경쟁  
→ 링컨-더글러스 논쟁으로 전국적인 주목  
→ 선거 자체는 패배  
→ 그러나 **면접은 떨어졌는데 업계 전체가 이름을 기억하게 된 상황**에 비유 가능

### 대통령 (51세 · 1860년)
→ 공화당 후보로 대통령 당선  
→ 남부 여러 주가 연방 탈퇴  
→ 취임 직후 남북전쟁 시작

### 나라가 둘로 갈라짐 (51–54세 · 1861–1863년)
→ 전쟁 수행과 동시에 정치적 연합 유지  
→ 장군들을 계속 교체하며 적합한 지휘관을 찾음  
→ 전쟁·의회·여론을 동시에 관리

### 노예해방선언 (53세 · 1863년)
→ 반란 상태에 있던 남부 지역의 노예를 자유인으로 선언  
→ 전쟁의 목표를 연방 보존에서 자유의 문제까지 확대  
→ 흑인 병사의 연방군 입대에도 길을 엶

### 게티즈버그 (54세 · 1863년)
→ 짧은 연설로 민주주의와 전쟁의 의미를 압축  
→ '국민의, 국민에 의한, 국민을 위한 정부'라는 표현이 상징이 됨

### 재선 (55세 · 1864년)
→ 전쟁 중 대통령 재선 성공  
→ 북군의 승리가 가시화

### 전쟁이 끝나가던 순간 (56세 · 1865년)
→ 남부의 주요 군대 항복  
→ 4월 14일 포드 극장에서 존 윌크스 부스에게 총격  
→ 다음 날 사망

## 캐릭터 요약

**INFJ 느낌**  
→ 큰 가치와 현실정치를 함께 고민하는 타입

**강점**  
→ 반대파까지 내각에 두며 여러 세력을 묶어냄  
→ 복잡한 문제를 짧고 기억되는 문장으로 전달

**특징**  
→ 정치적 실패가 많았지만 매번 경력을 이어감  
→ **계속 떨어져도 전국 단위 포지션까지 올라간 장기전형 커리어**

## 사실 / 비유 / 설

- **역사적 사실:** 1809년 출생, 제한된 정규교육과 독학, 주의원·변호사·하원의원 경력, 1858년 상원의원 선거 패배와 토론, 1860년 대통령 당선, 남북전쟁, 노예해방선언, 게티즈버그 연설, 재선, 1865년 암살.
- **비유:** 면접은 떨어졌는데 업계 스타, 장기전형 커리어, INFJ.
- **해석이 필요한 부분:** 링컨의 노예제·인종관은 생애 동안 변화했다. 결과만 보고 오늘날의 가치관을 그대로 투영하지 않는다.
- **주의:** 노예해방선언은 미국 전역의 모든 노예를 즉시 해방한 조치가 아니라 당시 반란 중인 지역을 대상으로 한 전시 조치였다.
