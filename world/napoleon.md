# 🇫🇷 나폴레옹 보나파르트

## 기본소개

**이름 : 나폴레옹 보나파르트**  
**업적 : 혁명 뒤 프랑스와 유럽의 질서를 재편함**  
**출생 : 1769년 코르시카 아작시오**  
**직업 : 군인, 정치가, 프랑스 황제**  
**MBTI : ENTJ 느낌**  
**취미 : 독서, 지도 보기, 수학·역사 공부, 전장 시뮬레이션**  
**특기 : 빠른 판단, 병력 집중, 조직 재편, 행정 시스템 만들기**  
**극혐 : 느린 의사결정, 우유부단, 통제 밖 변수, 지시를 못 알아듣는 부하**  
**성격 : 초고속 판단 + 강한 통제욕 + 엄청난 업무량**  
**좌우명 : 불가능은 프랑스어가 아니다 — 나폴레옹에게 흔히 연결되는 표현**

> 직업·조직·MBTI 등의 표현은 나폴레옹의 삶을 **오늘날 감각으로 이해하기 위한 비유**입니다. 유명 어록 가운데는 후대에 정리되거나 표현이 변형된 것도 있어 문구 자체를 1차 사료로 단정하지 않습니다.

## 요약

**코르시카 소년 → 프랑스 군사학교 → 16세 포병장교 → 혁명 혼란 속 초고속 승진 → 24세 장군 → 26세 이탈리아 원정 대박 → 30세 쿠데타로 국가 CEO급 권력 장악 → 35세 황제 → 유럽 대부분과 전쟁하며 정점 → 법·행정 시스템 대수술 → 43세 러시아 원정에서 대붕괴 → 퇴위·엘바섬 → 100일 복귀 → 워털루 패배 → 세인트헬레나 유배 → 51세 사망**

> **업적 : 전쟁영웅을 넘어 프랑스의 법·행정 체계까지 다시 짠 인물.**

## 인생

### 코르시카 출생 (0세 · 1769년)
→ 코르시카 아작시오에서 출생  
→ 프랑스에 편입된 지 얼마 되지 않은 지역에서 성장

### 군사학교 유학생 (9–15세 · 1779–1784년)
→ 프랑스 본토 군사학교에서 교육  
→ 프랑스어가 모국어가 아니었고 코르시카 억양이 강했음  
→ 수학·포병 분야에 강점을 보임

### 첫 취업 (16세 · 1785년)
→ 1785년 포병 장교 임관  
→ 오늘 식으로 보면 **수학 잘하는 기술병과 신입 장교**

### 혁명이 터진다 (24세 · 1793년)
→ 프랑스혁명으로 기존 군 조직이 흔들림  
→ 1793년 툴롱 공방전에서 활약  
→ 24세에 장군급으로 초고속 승진

### 스타 장군 (26–28세 · 1796–1797년)
→ 이탈리아 방면군 지휘  
→ 연속 승리로 유럽 전체에 이름을 알림  
→ 병사들에게 직접 메시지를 던지고 속도와 집중으로 전투를 풀어감

### 회사원이 회사를 인수함 (30세 · 1799년)
→ 이집트 원정 이후 프랑스로 귀환  
→ 브뤼메르 18일 쿠데타  
→ 통령정부의 제1통령이 되어 사실상 최고권력자

### 국가 리빌딩 (30–35세 · 1799–1804년)
→ 프랑스은행·교육·행정·훈장제도 등 정비  
→ 나폴레옹 법전(Code civil) 제정  
→ 혁명 이후 뒤섞인 사회 규칙을 **전국 공통 운영규정**으로 정리

### 황제 (35세 · 1804년)
→ 프랑스인의 황제로 즉위  
→ 1805년 아우스터리츠에서 대승  
→ 유럽 대륙의 가장 강력한 권력자로 올라섬

### 너무 크게 벌림 (40–43세 · 1809–1812년)
→ 유럽 전역에서 전쟁 지속  
→ 대륙봉쇄령 등으로 영국 압박  
→ 1812년 러시아 원정  
→ 보급·추위·퇴각 과정에서 대참사

### 첫 퇴사 (44세 · 1814년)
→ 연합군에 밀려 퇴위  
→ 엘바섬 유배

### 퇴사했다가 1년 안 돼 복귀 (45세 · 1815년)
→ 엘바섬 탈출  
→ 프랑스군과 국민의 지지를 얻으며 파리 복귀  
→ '백일천하'

### 마지막 프로젝트, 워털루 (45세 · 1815년)
→ 워털루 전투 패배  
→ 두 번째 퇴위  
→ 대서양 외딴 세인트헬레나섬으로 유배

### 유배지에서 사망 (51세 · 1821년)
→ 세인트헬레나에서 사망  
→ 군사적 정복은 무너졌지만 법·행정 개혁은 유럽 여러 지역에 장기적 영향

## 캐릭터 요약

**ENTJ 느낌**  
→ 목표 설정 · 속도 · 조직 통제 · 성과 집착

**강점**  
→ 혼란한 조직을 빠르게 정리하고 자원을 결정적 지점에 집중

**약점**  
→ 성공 경험이 커질수록 목표와 전선도 커짐  
→ 러시아 원정은 **잘하던 사람이 스케일을 너무 키웠을 때 생기는 대표적 리스크**로 볼 수 있음

## 사실 / 비유 / 설

- **역사적 사실:** 1769년 출생, 군사교육, 포병장교, 툴롱, 이탈리아 원정, 1799년 쿠데타, 제1통령, 1804년 황제 즉위, 나폴레옹 법전, 1812년 러시아 원정, 1814·1815년 퇴위, 워털루, 세인트헬레나 유배, 1821년 사망.
- **비유:** 국가 CEO, 회사 인수, 첫 퇴사·재입사, 국가 리빌딩, ENTJ.
- **해석이 필요한 부분:** 성격·극혐은 방대한 명령서와 정치·군사 행적을 압축한 것이다.
- **주의:** 나폴레옹은 법·행정 개혁가이면서 동시에 정복전쟁과 권위주의적 통치를 이끈 인물이다. 두 측면을 함께 본다.
