# 🇩🇪🇨🇭🇺🇸 알베르트 아인슈타인

## 기본소개

**이름 : 알베르트 아인슈타인**  
**업적 : 시간·공간·빛에 대한 물리학을 바꿈**  
**출생 : 1879년 독일 울름**  
**직업 : 이론물리학자, 교수**  
**MBTI : INTP 느낌**  
**취미 : 바이올린, 산책, 요트, 생각실험**  
**특기 : 복잡한 문제를 단순한 원리로 다시 보기, 머릿속 실험**  
**극혐 : 권위주의, 군국주의, 생각 없이 외우기, 당연하다고 넘기는 전제**  
**성격 : 독립적 + 장난기 + 깊은 집중 + 권위에 잘 안 눌림**  
**좌우명 : 중요한 것은 질문을 멈추지 않는 것 — 아인슈타인에게 널리 연결되는 태도**

> 직업·조직·MBTI 등의 표현은 아인슈타인의 삶을 **오늘날 감각으로 이해하기 위한 비유**입니다. 널리 퍼진 아인슈타인 명언 중에는 출처가 불분명한 것이 많으므로 문구보다 확인 가능한 행적을 우선합니다.

## 요약

**독일 출생 → 스위스로 이동 → 취리히 공대 → 졸업했는데 교수자리 못 구함 → 특허청 취업 → 퇴근 후 물리학 → 26세 논문 여러 편으로 물리학 판 뒤집음 → 특수상대성이론·광전효과·브라운운동 → 교수 스카우트 → 36세 일반상대성이론 → 40세 일식 관측으로 세계적 스타 → 42세 노벨상(광전효과) → 나치 집권 후 미국 이주 → 프린스턴 연구 → 이스라엘 대통령 제안도 거절 → 76세 사망**

> **업적 : 대학 자리도 못 구하던 특허청 직원이 물리학의 기본 틀을 다시 씀.**

## 인생

### 울름 출생 (0세 · 1879년)
→ 독일 울름에서 출생  
→ 가족은 곧 뮌헨으로 이동

### 학교 시스템과 잘 안 맞음 (15~16세 · 1894~1895년)
→ 암기·권위 중심 교육에 답답함을 느낌  
→ 수학·물리에는 강한 관심  
→ 가족이 이탈리아로 옮긴 뒤 스위스에서 학업 지속

### 취리히 공대 입학 (17세 · 1896년)
→ 스위스 연방공과대학에서 수학·물리 교사 과정  
→ 1900년 졸업

### 취업난 (21~23세 · 1900~1902년)
→ 대학 교직을 원했지만 바로 자리를 얻지 못함  
→ 1902년 베른 특허청 취업  
→ 낮에는 특허 심사, 밤에는 물리 연구

### 1905년, 갑자기 판이 바뀜 (26세 · 1905년)
→ 광전효과 설명  
→ 브라운운동 연구  
→ 특수상대성이론 발표  
→ 질량과 에너지 관계를 다룬 논문 발표  
→ 이른바 '기적의 해'

### 결국 대학이 데려감 (30~35세 · 1909~1914년)
→ 1909년 대학 교수로 전직  
→ 취리히·프라하 등에서 교수직 수행  
→ 1914년 베를린으로 이동

### 일반상대성이론 (36세 · 1915년)
→ 중력을 힘이라기보다 시공간의 구조와 연결해 설명  
→ 뉴턴 이후 중력 이해의 큰 틀을 바꿈

### 세계적인 스타 (40세 · 1919년)
→ 일식 관측 결과가 일반상대성이론의 예측과 부합한다고 발표되며 세계적 유명세  
→ 과학자가 대중 스타가 되는 드문 사례

### 노벨물리학상 (42세 · 1921년)
→ 상대성이론이 아니라 **광전효과 법칙 발견**에 대한 공로로 수상  
→ 실제 시상은 1922년에 이루어짐

### 나치 집권과 미국 이주 (54세 · 1933년)
→ 유대계였던 아인슈타인은 독일로 돌아가지 않음  
→ 미국 프린스턴 고등연구소에서 연구

### 핵무기 시대의 불편한 위치 (60세 · 1939년 이후)
→ 1939년 루스벨트 대통령에게 보낸 편지에 서명해 독일의 핵무기 가능성을 경고  
→ 그러나 맨해튼 프로젝트에 직접 참여하지는 않음  
→ 전후에는 핵무기 통제와 평화를 강조

### 대통령 제안 거절 (73세 · 1952년)
→ 이스라엘 대통령직 제안을 받았지만 거절

### 사망 (76세 · 1955년)
→ 미국 프린스턴에서 사망  
→ 상대성이론뿐 아니라 양자론의 출발에도 큰 영향을 남김

## 캐릭터 요약

**INTP 느낌**  
→ '이 전제가 진짜 맞나?'부터 다시 묻는 타입

**강점**  
→ 거대한 실험실 없이도 사고실험으로 문제의 핵심을 찾아냄  
→ 빛을 따라가면 어떻게 보일까 같은 질문을 끝까지 밀어붙임

**특징**  
→ 대표 성공 이전에 **교수 취업 실패 → 특허청**이라는 우회 경력이 있었음  
→ 오늘 식으로 보면 전공자 정규직 트랙에서 밀렸는데 사이드 프로젝트로 업계 법칙을 바꾼 사람

## 사실 / 비유 / 설

- **역사적 사실:** 1879년 출생, 취리히 공대, 특허청 근무, 1905년 주요 논문, 교수 임용, 일반상대성이론, 1921년 노벨상, 1933년 미국 이주, 프린스턴 연구, 이스라엘 대통령직 거절, 1955년 사망.
- **비유:** 취업난, 사이드 프로젝트, 업계 법칙 변경, INTP.
- **해석이 필요한 부분:** 학교를 '공부 못해서 낙제한 학생'으로 묘사하는 유명 이야기는 과장되기 쉽다. 수학·물리에 뛰어났고 교육방식과의 갈등을 구분해야 한다.
- **주의:** E=mc²만으로 아인슈타인의 업적을 요약하면 광전효과·브라운운동·일반상대성이론 등의 기여가 빠진다.
