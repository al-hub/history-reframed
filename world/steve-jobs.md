# 🇺🇸 스티브 잡스

## 기본소개

**이름 : 스티브 잡스**  
**업적 : 컴퓨터를 기술에서 생활도구로 끌어옴**  
**출생 : 1955년 미국 샌프란시스코**  
**직업 : 기업가, 제품기획자, 애플 공동창업자**  
**MBTI : ENTJ 느낌**  
**취미 : 음악, 산책하며 회의, 명상, 디자인 관찰**  
**특기 : 제품 비전, 단순화, 프레젠테이션, 좋은 팀을 모아 끝까지 밀어붙이기**  
**극혐 : 복잡한 버튼, 타협된 디자인, 평범한 결과물, 느린 의사결정**  
**성격 : 집요함 + 강한 기준 + 극단적 집중 + 사람을 몰아붙이는 리더십**  
**좌우명 : Stay hungry. Stay foolish.**

> 직업·조직·MBTI 등의 표현은 스티브 잡스의 삶을 **오늘날 감각으로 이해하기 위한 비유**입니다. 성격 평가는 동료 증언과 공개 행적을 단순화한 것이며 실제 MBTI 결과가 아닙니다.

## 요약

**입양 → 전자기기 덕후 청소년 → 리드칼리지 입학 → 6개월 만에 자퇴 → 청강은 계속 → 인도 여행·명상 → 21세 차고에서 Apple 창업 → Apple II 성공 → 29세 Macintosh → 30세 자기가 만든 회사에서 쫓겨남 → NeXT 창업 + Pixar 인수 → Pixar 대성공 → Apple이 NeXT 인수하며 42세 복귀 → iMac → iPod → iTunes → iPhone → iPad → 세상을 바꾼 제품 발표의 아이콘 → 56세 사망**

> **업적 : 기술 자체보다 사람이 실제로 쓰는 경험을 제품의 중심에 놓음.**

## 인생

### 샌프란시스코 출생·입양 (0세 · 1955년)
→ 출생 직후 폴 잡스와 클라라 잡스 부부에게 입양  
→ 캘리포니아에서 성장

### 전자기기와 반문화 (16–17세 · 1971–1972년)
→ 실리콘밸리의 전자공학 문화 속에서 성장  
→ 스티브 워즈니악과 친해짐  
→ 기술뿐 아니라 음악·디자인·동양사상에도 관심

### 대학 입학 (17세 · 1972년)
→ 리드칼리지 입학  
→ 약 6개월 뒤 정규과정 자퇴  
→ 학교를 완전히 떠나기 전까지 관심 있는 수업을 청강  
→ 훗날 Macintosh의 타이포그래피 감각과 연결해 회고

### 인도 여행과 탐색 (19세 · 1974년)
→ 인도 여행  
→ 명상·선불교 등에 깊은 관심  
→ 이후 제품 철학의 단순함·집중과 연결해 해석되는 경우가 많음

### 차고 창업 (21세 · 1976년)
→ 스티브 워즈니악, 로널드 웨인과 Apple Computer 창업  
→ Apple I 판매 시작

### Apple II (22세 · 1977년)
→ Apple II가 큰 성공  
→ 개인용 컴퓨터 시장의 주요 기업으로 급성장

### Macintosh (29세 · 1984년)
→ 그래픽 사용자 인터페이스와 마우스를 앞세운 Macintosh 출시  
→ 컴퓨터를 전문가 기계에서 일반 사용자가 만지는 제품으로 바꾸려는 방향을 강하게 밀어붙임

### 창업자 해고급 사건 (30세 · 1985년)
→ 경영진·이사회와 갈등  
→ 자신이 만든 Apple에서 실질적으로 밀려남  
→ 스스로도 훗날 '해고당했다'고 표현

### 두 번째 인생 (30–39세 · 1985–1994년)
→ NeXT 창업  
→ 1986년 루카스필름의 컴퓨터 부문을 인수해 Pixar로 독립  
→ 기술·교육용 컴퓨터와 컴퓨터 애니메이션에 동시에 투자

### Pixar 대박 (40세 · 1995년)
→ 『Toy Story』 성공  
→ Pixar가 애니메이션 산업의 핵심 회사로 성장

### Apple 복귀 (42세 · 1997년)
→ Apple이 NeXT를 인수하면서 복귀  
→ 제품 라인업을 대폭 줄이고 핵심 제품에 집중  
→ 오늘 식으로는 **퇴사자가 망해가는 회사에 돌아와 구조조정부터 한 상황**

### iMac·iPod (43–46세 · 1998–2001년)
→ iMac으로 브랜드와 제품 경험 재정비  
→ 2001년 iPod 출시  
→ iTunes와 결합해 음악 소비방식 변화

### iPhone (52세 · 2007년)
→ 전화·인터넷·음악기기를 하나의 멀티터치 기기로 통합  
→ 스마트폰 산업의 사용자경험 기준을 크게 바꿈

### iPad (55세 · 2010년)
→ 태블릿 시장을 대중화  
→ 컴퓨터·휴대전화 사이의 새로운 제품군을 확장

### 사망 (56세 · 2011년)
→ 건강 문제로 CEO에서 물러난 뒤 2011년 10월 사망  
→ Apple은 이후에도 그가 구축한 제품·디자인 중심 문화의 영향을 이어감

## 캐릭터 요약

**ENTJ 느낌**  
→ 큰 그림을 그리고 사람과 조직을 강하게 밀어붙이는 타입

**강점**  
→ 기술이 가능한 것보다 사용자가 무엇을 느끼는지를 앞에 둠  
→ 하드웨어·소프트웨어·서비스·매장까지 하나의 경험으로 묶음

**약점**  
→ 기준이 지나치게 높고 대인관계가 거칠었다는 증언이 많음  
→ 좋은 제품을 만든다는 목표가 사람에게 큰 압박으로 작용하기도 함

**특징**  
→ 인생의 핵심 반전은 Apple에서 쫓겨난 뒤 NeXT와 Pixar를 만든 것  
→ 실패가 없었다면 오히려 두 번째 전성기도 없었을 가능성이 큼

## 사실 / 비유 / 설

- **역사적 사실:** 1955년 출생과 입양, 리드칼리지 자퇴, 1976년 Apple 공동창업, Apple II, Macintosh, 1985년 Apple 이탈, NeXT, 1986년 Pixar, 1997년 Apple 복귀, iMac·iPod·iPhone·iPad, 2011년 사망.
- **비유:** 창업자 해고급 사건, 퇴사자가 돌아와 구조조정, ENTJ.
- **해석이 필요한 부분:** Apple 제품은 잡스 혼자 만든 것이 아니다. 워즈니악, 조니 아이브, 소프트웨어·하드웨어·마케팅 조직 등 수많은 팀의 결과다.
- **주의:** 잡스를 '발명가 한 명이 모든 것을 발명했다'고 묘사하기보다 제품 방향을 선택하고 팀을 조직해 결과물을 통합한 리더로 보는 편이 정확하다.
