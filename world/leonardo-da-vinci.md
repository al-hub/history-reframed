# 🇮🇹 레오나르도 다 빈치

## 기본소개

**이름 : 레오나르도 다 빈치**  
**업적 : 예술과 과학을 한 사람 안에서 연결함**  
**출생 : 1452년 이탈리아 빈치**  
**직업 : 화가, 설계자, 기술자, 해부·자연 연구자**  
**MBTI : INTP 느낌**  
**취미 : 스케치, 해부 관찰, 기계 구상, 물·새·인체 관찰, 노트 쓰기**  
**특기 : 관찰, 드로잉, 서로 다른 분야를 연결하기**  
**극혐 : 지루한 반복, 분야 칸막이, 대충 보고 넘어가기**  
**성격 : 끝없는 호기심 + 관찰 집착 + 아이디어 과다 + 미완성도 많음**  
**좌우명 : 보이는 것을 끝까지 관찰하자**

> 직업·조직·MBTI 등의 표현은 레오나르도의 삶을 **오늘날 감각으로 이해하기 위한 비유**입니다.

## 요약

**시골 출생 → 정규 대학 대신 공방 도제 → 베로키오 작업실에서 미술·기술 종합훈련 → 화가조합 가입 → 30세쯤 밀라노 이직 → 화가인데 군사기술·건축·무대·기계까지 제안 → 『최후의 만찬』 → 인체 해부·비행·물·기계 연구 → 『모나리자』 → 프로젝트는 엄청 많은데 완성작은 적음 → 프랑스 국왕 초청으로 말년 이주 → 67세 사망**

> **업적 : 전공을 하나로 정하지 않고 예술·과학·기술을 하나의 관찰 문제로 다룸.**

## 인생

### 빈치 출생 (0세 · 1452년)
→ 피렌체 인근 빈치에서 출생  
→ 공증인인 아버지와 혼외 관계에서 태어남

### 공방 입사 (17세 · 1469년 무렵)
→ 피렌체의 안드레아 델 베로키오 공방에서 수련  
→ 회화뿐 아니라 조각·금속·기계·제작기술을 함께 접함  
→ 오늘 식으로는 **미술대학 + 공대 + 제작랩이 한 건물에 있는 곳에서 도제생활**

### 프로 화가 등록 (20세 · 1472년)
→ 성 루카 조합에 가입  
→ 독립적인 화가로 활동할 기반 확보

### 밀라노 이직 (30세 · 1482년 무렵)
→ 약 1482년 밀라노로 이동  
→ 루도비코 스포르차에게 자신의 능력을 소개  
→ 회화보다 먼저 군사기술·토목·기계 능력을 강조한 것으로 유명

### 멀티직군 정점 (30–47세 · 1482–1499년)
→ 궁정 화가·설계자·기술자 역할  
→ 축제 무대, 수로, 건축, 무기 아이디어 등 폭넓은 프로젝트 수행  
→ 1490년대 『최후의 만찬』 제작

### 다시 피렌체 (47–51세 · 1500–1503년 무렵)
→ 밀라노 정세 변화로 여러 지역을 이동  
→ 1500년 무렵 피렌체 복귀  
→ 1503년 무렵 『모나리자』 작업 시작

### 그림보다 노트가 더 많아짐 (55–61세 · 1507–1513년 무렵)
→ 인체 해부 연구  
→ 근육·뼈·장기 구조를 세밀하게 기록  
→ 물의 흐름, 비행, 광학, 기계장치 등을 수천 장의 드로잉으로 남김

### 프랑스로 스카우트 (64세 · 1516년 무렵)
→ 1516년경 프랑수아 1세의 초청을 받아 프랑스로 이동  
→ 말년을 클로 뤼세에서 보냄

### 사망 (67세 · 1519년)
→ 프랑스 앙부아즈 인근에서 사망  
→ 완성된 작품 수보다 노트와 아이디어가 훨씬 많았던 인물로 남음

## 캐릭터 요약

**INTP 느낌**  
→ 질문이 생기면 전공 경계 없이 파고드는 타입

**강점**  
→ 눈으로 관찰한 것을 그림으로 정밀하게 기록  
→ 미술이 연구 도구이고 연구가 다시 미술의 정확성을 높이는 구조

**약점**  
→ 관심사가 너무 많아 프로젝트를 끝까지 마무리하지 못한 경우가 많음  
→ 오늘 식으로 보면 **아이디어 백로그가 무한히 늘어나는 천재형 메이커**

## 사실 / 비유 / 설

- **역사적 사실:** 1452년 출생, 베로키오 공방 수련, 1472년 화가조합 가입, 밀라노 궁정 활동, 『최후의 만찬』·『모나리자』, 해부·자연·기계 연구, 프랑스 이주, 1519년 사망.
- **비유:** 미술대학+공대+제작랩, 멀티직군, 아이디어 백로그, INTP.
- **해석이 필요한 부분:** 현대적 의미의 과학자·공학자라는 직함을 그대로 적용하기보다 르네상스기의 예술가·기술자·자연 탐구자로 이해한다.
- **후대의 설·야사:** 헬리콥터·탱크 등을 '실제로 발명해 운용했다'고 표현하는 것은 과장이다. 관련 스케치와 개념 연구를 남긴 것이다.
